# Dongheng Lin — Nostalgia 1990s homepage

This branch adapts [academic-homepage's Nostalgia 1990s variant](https://github.com/luost26/academic-homepage-nostalgia-1990s) to the existing personal site. Content, URLs, gallery data, publications, weather and Live2D interactions remain in their original Jekyll files.

- Alice, Marisa and Patchouli use blue-grey, warm-gold and muted-violet night palettes within the classic Windows 95/98 frame. Use the three pixel portraits in the header to select a theme; the choice persists across pages and reloads.
- All three characters use portraits supplied by the site owner, including the updated Alice illustration. Each frame has original pixel ornaments: Alice's ribbon and doll, Marisa's star and witch hat, and Patchouli's crescent and grimoire. Frames follow the selected palette and use smaller ornaments on mobile.
- Optional **声：入** adds occasional recorded Japanese interjections (18 clips, each under a second), chosen for dialogue emotion. It starts off on every visit, avoids consecutive repeats and respects a five-second cooldown per character. Dialogue stays text-led. [Voice sources](docs/companion-voices.md).
- A skeuomorphic FM **BGM：** receiver lives inside **Playground**. RADIO and **PV** share 13 songs selected from the site owner's supplied music library. RADIO plays local MP3s, with bundled LRC lyrics; PV offers the corresponding official music video or official audio upload. The receiver starts silent and loads audio only after Play/Unmute. Switching modes keeps the selected song, stops the preceding source and waits for Play. YouTube loads only after explicit PV playback. Short Japanese introductions accompany manual and automatic track changes, with an audible one-second FM sweep/static sequence before the song starts. Lyrics follow each source's own clock, with optional local imports and timing adjustment. Playback survives page navigation and pauses with the hidden/minimized companion or arcade. [Radio library and version notes](assets/music/radio/README.md); [separate battle-music credits](assets/music/danmaku/README.md).
- Gallery thumbnails use a consistent 4:3 crop; the full-size viewer preserves each original aspect ratio.
- Gallery uses the template’s native showcase/archive organization. Notes and Thoughts retain their original source files. Jekyll renders gallery cards from the existing YAML, so images and original-image links also work without JavaScript. The viewer enhances these links with a thumbnail placeholder while full-size files decode, keyboard navigation and focus containment.
- The PC-98-style **Playground** window docks below the in-page navigation in the profile rail on desktop and can be dragged, resized from its lower-right grip (arrow keys: 16px; Shift: 1px), maximized/restored, minimized or closed. Desktop maximum size is centered at about 75% of the screen’s width and height. Fonts, icons, pixel effects and controls share one proportional scale. Wide resized windows use two columns; the model is rerendered to match its new stage. Use the pixel reset button beside Minimize, double-click the title bar, press Home, or use 設定 → 元の位置へ to restore the current layout’s dock. Mobile/tablet starts enabled at the page bottom below the section index; **Options → Playground を開く** restores it after closing. Desktop and mobile visibility preferences are independent. Half-body framing, three softly defocused scenes and subtle ambient light accompany the original models.
- The interface and body use W95FA, with 17px desktop body text. Japanese dialogue and menus use locally hosted Fusion Pixel (SIL OFL). Original pixel character icons and low-contrast ribbon/star/moon night wallpaper change with each palette. Portraits use a closer crop; contact icons share a 16-pixel grid. SVG source artwork is in `assets/images/classic/characters/` and `patterns/`.
- All 465 companion lines have explicit facial expressions and body poses using the original three models, including Patchouli's book gestures. Expressions persist through reading, and rapid dialogue changes retain the latest requested pose.
- **弾幕に挑戦** offers music-synchronized score attack and a Flower-style duel against the CPU. Three pilots have distinct shots, eight-direction flight animations, satellites and power upgrades. Each opponent rotates six spell cards and six nonspells to their supplied dBu recording, with timed phases, durability clears, graze scoring, supply drops, Bombs and automatic play. A completed track pauses for the boss’s continuation dialogue while retaining cumulative score. BGM and effects have independent controls; they start off in the embedded window and enabled on the standalone page, independently of the radio. [Game rules and implementation](docs/danmaku-game.md).
- The desktop homepage profile rail follows scrolling as a whole; tall rails can scroll fully before pinning at the viewport edge. The reading layout uses theme-colored pixel section icons, an education timeline, publication metadata beside unobstructed previews, and a section index that follows the current reading position. Gallery collections include image counts; all previews keep the same crop.
- The Japanese-only companion has 228 everyday/holiday/affinity lines, 117 branching-conversation lines and 18 unchanged original game quotations. Each character now has three additional selectable topics, with three opening questions and two follow-ups per answer; nine conclusions vary with affinity. Completed ordinary dialogue offers topic suggestions, and friend remarks offer continue/back controls. **友人のこと** contains 102 remarks across 34 speaker/subject entries (Alice 10, Marisa 14, Patchouli 10), covering 22 characters/groups with established interactions. Three remarks per acquaintance and independent topic/context shuffle bags add variety without repeating a line until its pool is exhausted. Four affinity tiers, branching replies, seven holiday groups, weather/time context, typewriter text, auto advance and history remain. **設定** controls affinity, text speed and ambient light, including a 0–100% strength slider for scene-colored model lighting; source/subtitle/help metadata has been removed from the interface. Details: [companion system](docs/companion-system.md).
- Original flat squadron insignia give each theme a distinct corner watermark: Alice’s puppet and ribbons, Marisa’s hat and broom, and Patchouli’s crescent and grimoire. The full-resolution illustrations stay subtle, with no pixel conversion or artwork in empty side rails. [Artwork provenance](assets/images/classic/corners/README.md).
- The dedicated [Playground page](https://rathgrith.github.io/playground/) uses a large scene, a fixed dialogue desk and a separate radio panel, with portrait and landscape layouts. The radio always waits for explicit Play; battle music defaults enabled only here. Dialogue and choices stay within a fixed-height reading area in both standalone and floating windows.
- **非想天則** is a theme-tinted weather terminal with a local dot-matrix world map, observation marker, 24-hour temperature/rain forecast and 21 Touhou-inspired weather symbols. A compact calendar line shows the Gregorian date, Japanese old-calendar date and Gensokyo season; the clock follows the visitor’s local time. [Calendar data and conventions](docs/weather-calendar.md).
- Retained features include: publication filtering, hover previews, full gallery viewer, weather, runtime and Live2D dialogue. Visitor tracking, analytics scripts and page-view counters have been removed.
- Shared chrome is in `_layouts/default.html` and `_includes/masthead.html`. The frontend now has a single modular stylesheet system, with the old template CSS, paper/glass redesign, jQuery plugins and old standalone player code retired. See [frontend structure and regression checks](docs/frontend-architecture.md).
- Template licensing is retained in `docs/nostalgia-template-LICENSE`; font and icon provenance is alongside those assets and in the page credits.

## Local preview

Use Ruby 2.7.8 and the locked gems, then run `bash run_server.sh`. This script sets the UTF-8 locale required by the existing Sass sources. To build without serving:

```sh
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 bundle exec jekyll build
```

The Pages workflow deploys `main`. Release through a reviewed pull request, merge it, then verify the resulting Pages run and the homepage, Gallery and `/playground/` routes. Development scripts, tests and docs are excluded from the published site. Live2D models, weather data and gallery originals keep their existing remote sources.
