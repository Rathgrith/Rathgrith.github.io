# Playground radio sources

Verified on **2026-10-10**. RADIO and PV share one 16-item catalog with six creator-hosted audio previews and thirteen creator/publisher videos; three XFD entries have both sources. The ten requested PV-only favorites are retained. Native audio provenance is in [AUDIO-RADIO.md](AUDIO-RADIO.md). For PV, the player links to the official YouTube uploads; no music audio or video is downloaded, extracted, or redistributed with the site. Danmaku challenge music remains a separate system, documented in [CREDITS.md](CREDITS.md).

The `theme` field in `assets/js/data/companion-radio.js` names the original Touhou composition, not a character restriction. The queue mixes artists and source games. `MV` denotes an official full-track video or music-video edit; `XFD` denotes an album crossfade preview. A freely viewable upload is not a free license to copy its audio.

## Captions and timed-lyrics availability

Caption-track metadata was checked on 2026-10-10 without downloading or reproducing lyric text. The ten favorite records' `duration` values describe their selected videos; paired preview records retain their native-audio durations. Both are metadata hints, and the active provider remains the authority for duration and playback position. The `captions` field records the following observed support:

| Caption status | Selected videos |
| --- | --- |
| `manual-translations`: translated captions available, no Japanese track found | Necromantic (Traditional Chinese, English, Korean); インスタントブルー (Thai, English, Korean, Traditional Chinese) |
| `auto-ja`: Japanese automatic captions only; not verified lyric transcription | 斑にマーガレット |
| `auto-other`: only an unrelated automatic-recognition language advertised, not usable Japanese lyrics | 物凄い狂っとるフランちゃんが物凄いうた (Indonesian automatic recognition on the selected official upload) |
| `none`: no caption tracks advertised | 月齢11.3のキャンドルマジック; ブロッケンのまるい虹; Bad Apple!! selected shadow-animation version; Opposite World; miscalc; Fall in the Dark |

The StarryMirage Patchouli reference advertised only an unrelated Hindi automatic-recognition track, so it is not a usable Japanese lyric source. The user's Flan karaoke reference advertises Japanese automatic captions and has captions burned into its video; this does not make them a licensed text feed for the site's own player. Missing metadata on future XFD entries means not audited for captions, not a claim that captions exist.

Visitors can import their own local LRC file for the current recording without uploading it or committing it to the repository. Native audio and PV use separate lyric keys, so video lead-ins do not shift the audio version’s lyrics. Mode changes retain the catalog item but do not transfer its playback timestamp. No third-party full-lyric files are bundled here.

External API research:

- [YouTube captions.download](https://developers.google.com/youtube/v3/docs/captions/download) requires permission to edit the video. It is not a public caption-export endpoint for arbitrary songs. The standard embedded player's CC remains available where the uploader supplied captions.
- [LRCLIB's documented API](https://lrclib.net/docs) is free and CORS enabled, supports LRC timestamps, and requires an identifying client header. Its open API/code does not itself establish rights-holder permission for every contributed lyric. No LRCLIB lyric text has been copied or API integration activated.
- [Musixmatch's official API documentation](https://www.postman.com/musixmatch-dev/musixmatch-apis/overview) describes a licensed catalog and requires a plan plus API credentials. Free full synchronized lyrics for these specific tracks were not verified. No account, paid plan, credentials, or usage tracking was added.

## Embed behavior

RADIO and PV retain the same catalog entry on mode changes, stop the previous provider and wait for explicit playback. A missing `src` / `videoId` is shown as `PVのみ` / `RADIOのみ`; playback is disabled while previous/next and automatic advancement skip unsupported entries. Load third-party player code and the `youtube-nocookie.com` embed only after selecting PV and taking an explicit playback action. Do not fetch remote thumbnails or preconnect to YouTube on an ordinary page visit. Keep an external official-video link available.

[YouTube's IFrame API reference](https://developers.google.com/youtube/iframe_api_reference) requires a player viewport of at least 200 × 200 pixels. The video must remain visible while playing; do not use a hidden audio-only iframe. Privacy-enhanced embeds still connect to YouTube when activated: they are separate from visitor analytics and must not be described as making no third-party requests.
